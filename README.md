# WebVTT 字幕时序修复器

一款**完全本地运行**的 WebVTT（`.vtt`）字幕时序修复工具。粘贴或导入字幕后，可以直接在时间轴上拖动片段及其边界，修复重叠、间隔过小、时长不足等问题。锁定片段不会被任何调整推动；当约束无解时，本次调整会被自动撤销，并在时间轴上标出冲突区间。

内置**画面布局预览**：解析所选片段的 `line` / `position` / `size` / `align` 设置，在 16:9 预览区中绘制字幕框与 10% 安全区；非法布局值或字幕框越出安全区会进入问题清单，点击即可定位片段。四个布局字段可在检查器中独立编辑，修改时其余未知 cue 设置的原始顺序与内容保持不变。

技术栈：**React 18 + TypeScript + Vite**，纯前端，无后端，数据不离开浏览器。

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

启动后用浏览器访问：

> **http://localhost:8080**

停止：`Ctrl+C`；后台运行：`docker compose up --build -d`；停止并移除容器：`docker compose down`。

如 8080 端口被占用，修改 `docker-compose.yml` 中的 `"8080:80"`（例如 `"9090:80"`）即可。

## 本地开发（无需 Docker）

```bash
npm install
npm run dev        # 开发服务器，访问 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建

```

## 使用方法

1. **导入字幕**：点击右上角「粘贴 / 导入」，选择 `.vtt` 文件，或直接粘贴 WebVTT 文本后「解析并载入」。首次打开会自动载入一份带问题的示例字幕。
2. **在时间轴上调整**：
   - 拖动片段**中部**：整体平移（保持时长）；
   - 拖动片段**左/右边缘**：修改开始/结束时间（改变时长）；
   - 滚轮区域上方有「－ / ＋ / 适应窗口」可缩放时间轴，也可横向滚动。
3. **锁定片段**：点击列表中的 🔓，或在右侧检查器勾选「锁定」。锁定片段在任何拖动传播中**绝不移动或改变时长**。
4. **约束设置**（右侧栏）：
   - **最小片段时长**：任何片段（含被传播压缩的片段）不得短于该值；
   - **相邻片段间隔**：相邻片段之间至少保留的间隔。
5. **冲突传播规则**：
   - 向右拖动时，压力按操作方向**向右传播**：后续片段先整体平移，撞到锁定片段时再从近到远收缩到最小时长；
   - 向左拖动为镜像过程，边界为锁定片段或时间轴起点 `00:00.000`；
   - 传播后仍无法满足全部约束时，调整**自动撤销**，红色斜纹标出冲突区间，并在时间轴下方显示原因横幅；
   - 再次开始拖动或手动编辑后，冲突标记自动清除，也可点击「消除标记」。
6. **实时反馈**：
   - 时间轴上红色斜纹 = 重叠/非法时间（错误），黄色虚线斜纹 = 间隔不足/时长不足（警告）；
   - 右侧「问题清单」列出全部时序与布局问题，点击任一问题会选中并滚动到对应片段；
   - 悬停片段可在底部查看精确时间码与时长，拖动时有跟随的时间提示。
7. **精确编辑**：选中片段后在右侧检查器手动输入时间码（支持 `MM:SS.mmm` 与 `HH:MM:SS.mmm`，逗号小数点亦可）、编辑多行文本、cue 设置（`line`/`position`/`align` 等）与标识符，可复制或删除片段。
8. **画面布局预览与编辑**：
   - 右侧「画面布局预览」按 16:9 画面绘制所选片段的字幕框，并标出四边各内缩 10% 的安全区（黄色虚线）；
   - 字幕框位置按 WebVTT 渲染规则估算：宽 = `size`（默认 100%），高 = 行数 × 5.33% 行高；水平由 `position`（默认 50%）与位置对齐（未指定时随 `align` 推导）决定；垂直由 `line`（百分比 / 行号，缺省贴底）决定；
   - 非法布局值（如 `size:120%`、`align:top`）计入问题清单（错误），字幕框越出安全区计入问题清单（警告，仅检测显式设置了布局字段的片段）；
   - 检查器中 `line` / `position` / `size` / `align` 四个字段可独立编辑：已存在的字段原位替换，新字段追加到末尾，清空即删除该字段——其余 cue 设置（如 `vertical:rl`、自定义字段）的原始顺序与内容保持不变，非法输入即时标红。
9. **导出**：点击「导出 WebVTT」下载修复后的 `.vtt` 文件。导出内容为规范 WebVTT：
   - 字幕文本（含多行、内联标签如 `<b>`、时间戳标签）原样保留；
   - cue 设置与 cue 标识符原样保留；
   - 文件头中的 `NOTE` / `STYLE` / `REGION` 块原样写回；
   - 时间戳规范化为 `HH:MM:SS.mmm`（不足 1 小时为 `MM:SS.mmm`）；
   - 锁定状态仅属于编辑器状态，不会写入文件。

> 注意：右侧检查器中的手动时间码输入为**直接设置**（便于精确修正），不会触发跨片段传播；跨片段传播只在时间轴拖动时发生。手动编辑造成的重叠/间隔问题会立即出现在问题清单中，可再用拖动方式修复。

## 项目结构

```
.
├── docker-compose.yml      # 一条命令启动（映射 8080 -> 80）
├── Dockerfile              # 多阶段构建：node 构建 + nginx 静态服务
├── nginx.conf              # SPA 回退配置
├── index.html
├── src
│   ├── App.tsx             # 状态编排与布局
│   ├── lib
│   │   ├── types.ts        # Cue / Settings / Issue / Conflict 类型
│   │   ├── time.ts         # 时间戳解析与格式化
│   │   ├── vtt.ts          # WebVTT 解析与序列化
│   │   ├── solver.ts       # 核心：约束传播求解（锁定/最小时长/间隔/撤销）
│   │   ├── issues.ts       # 问题清单检测（时序 + 画面布局）
│   │   ├── layout.ts       # 布局解析：line/position/size/align、字幕框与安全区
│   │   └── sample.ts       # 内置示例字幕
│   ├── components
│   │   ├── Timeline.tsx    # 时间轴：泳道、拖动、冲突标注、缩放
│   │   ├── CueList.tsx     # 片段列表
│   │   ├── Inspector.tsx   # 片段检查器（含四个布局字段的独立编辑控件）
│   │   ├── LayoutPreview.tsx # 16:9 画面布局预览（字幕框 + 10% 安全区）
│   │   ├── SettingsPanel.tsx
│   │   ├── IssuesPanel.tsx
│   │   ├── TimeCodeInput.tsx
│   │   └── ImportModal.tsx
│   └── main.tsx
└── scripts/sanity-test.ts  # 核心逻辑测试（npm test）
└── README.md
```
